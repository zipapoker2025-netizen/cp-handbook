# CP 當班手冊（ZIPA POKER）

中華國際德州撲克協會 CP 當班手冊的網頁版。內容依 2026-09-24 CP 會議決議整理，
排版依 `ZIPA_可攜品牌包_2026-09-28`（1A Federation Standard）。

**對內資料，不得對外發布。** 手冊內容以通關碼加密（AES-256-GCM，金鑰由通關碼經 PBKDF2 產生），
repo 公開也看不到內容；進入網頁需輸入通關碼。通關碼請口頭或私訊告知 CP，勿寫進 repo。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁外框：通關碼畫面、工具列、版面與列印樣式 |
| `content.js` | 手冊內容（已加密）。用網頁「匯出 content.js」更新 |
| `gate.js` | 通關碼驗證、線上編輯、列印、匯出 |
| `styles.css`、`tokens/` | 品牌包的樣式與色彩 token，原樣複製，**不要修改** |
| `assets/logo-zipa-poker.png` | 品牌包的全彩標誌，原樣複製 |
| `check.mjs` | 品牌包的驗收工具 |

## 改內容（線上編輯）

1. 打開網頁、輸入通關碼，按上方「編輯」，直接點文字修改。修改會自動存在**這個瀏覽器**。
2. 狀態標籤（已決議／待補／建議）可直接複製既有的標籤再改字。
3. 改版時記得更新封面的版號、日期，以及文末「版本紀錄」表格。
4. 改完按「匯出 content.js」，到 GitHub repo 用 Add file → Upload files 上傳，覆蓋原本的 `content.js` 並 commit。約 1 分鐘後網站更新，所有人都會看到。
5. 不想保留本機修改時，按「還原發布版」。

`content.js` 已加密，無法在 GitHub 上直接編輯，請一律用網頁匯出。

## 列印／存成 PDF

按工具列「列印／存 PDF」→ 目的地「另存為 PDF」→ 紙張 A4 → 邊界「預設」→ 勾選「背景圖形」。
工具列與通關碼畫面不會出現在列印結果中。

交付到雲端硬碟的 PDF 依 D11 命名，例如 `ZIPA_20261001_NA_NA_doc_v01.pdf`。
